# Biblioimpressora

## Sobre o projeto

A Biblioimpressora é um projeto de extensão que busca aproximar a comunidade da literatura e da cultura local por meio da tecnologia.

A proposta é desenvolver um terminal interativo capaz de imprimir gratuitamente conteúdos como poesias de autores locais, charges e desenhos para colorir, utilizando impressora térmica e materiais reaproveitados.

O projeto é desenvolvido em parceria com a Biblioteca Municipal de Camaquã e a Casa do Poeta Camaquense.

## Objetivos

* Incentivar a leitura e o contato com a produção literária local.
* Valorizar autores e a cultura de Camaquã.
* Promover o acesso gratuito aos conteúdos disponibilizados.
* Reaproveitar equipamentos eletrônicos e incentivar o uso consciente de recursos.
* Integrar tecnologia, educação e comunidade.

## Estrutura do repositório

* `codigo/` — código-fonte do terminal.
* `conteudo/poesias/` — poesias autorizadas para publicação.
* `conteudo/charges/` — charges autorizadas para publicação.
* `conteudo/desenhos/` — desenhos disponibilizados para impressão.
* `documentacao/` — documentação técnica e manuais.
* `imagens/` — fotografias e imagens do projeto.
